A heading that divides a flat list into named runs — the only structure a list gets.

```jsx
<TaskGroupHeader title="Slides and notes" />
<TaskGroupHeader title="This Evening" tone="quiet" count={3} onToggle={t} />
```

Blue `accent` for user-created headings inside a project; grey `quiet` for system groupings like date buckets. The hairline rule beneath it is the only horizontal rule in a list.
