States when a to-do is due, scheduled, or was completed. The glyph carries the meaning; the text is plain.

```jsx
<DateChip kind="today">Today</DateChip>
<DateChip kind="deadline" secondary="5 days left">Tue, 2 Apr</DateChip>
<DateChip kind="scheduled" size="sm" muted>Fri</DateChip>
```

There is no background fill — a DateChip is a glyph plus a word. Only the glyph is coloured, and only ever in the state colour for its kind.
