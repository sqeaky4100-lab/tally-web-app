A bare glyph target for toolbars, row affordances and panel headers.

```jsx
<IconButton icon="ellipsis" label="More" />
<IconButton icon="tag" label="Tags" active />
<IconButton icon="trash-2" label="Delete" tone="danger" />
```

Rests at `--text-tertiary` and only darkens on hover, so a toolbar reads as quiet until touched. `label` is required.
