Single-line or multiline text entry.

```jsx
<TextField icon="search" placeholder="Quick Find" size="sm" />
<TextField multiline placeholder="Notes" variant="bare" />
```

Use `variant="bare"` wherever the user edits content in place — to-do titles, notes, checklist items. Boxed fields are only for genuine forms and search. Focus draws a blue hairline plus a 3px soft ring; it never grows the field.
