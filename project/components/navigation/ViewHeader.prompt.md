The large title at the top of a list — the only place display-scale type appears in the app.

```jsx
<ViewHeader icon="star" iconColor="var(--state-today)" title="Today" />
<ViewHeader progress={0.4} title="Prepare Presentation" subtitle="Keep the talk and slides simple." />
```

28px bold with tight tracking. The header sits on the canvas with no rule beneath it; the gap to the first row does the separating.
