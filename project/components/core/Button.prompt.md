The standard action control — use for anything that commits, cancels, or navigates deliberately.

```jsx
<Button variant="primary" icon="plus">New To-Do</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost" size="sm" icon="filter">Filter</Button>
```

Variants: `primary` (one per view, solid blue), `secondary` (white with a hairline border — the default), `ghost` (transparent, tints on hover; toolbars), `danger`. Sizes `sm` 26px / `md` 32px / `lg` 38px. `pill` for floating and filter actions. Press shrinks to 0.975.
